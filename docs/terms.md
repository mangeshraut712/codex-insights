# Terms of use

Codex Insights is a community plugin for Codex. It is MIT-licensed software, not an official OpenAI or Anthropic product. Codex has no native `/insights` command.

## Acceptable use

- Run the plugin only against Codex sessions you are allowed to analyze on this machine.
- Do not use it to exfiltrate other people’s transcripts or to bypass access controls.
- Do not present a generated report as a billing statement or as an official Codex `/usage` screen.
- Do not submit session contents or reports to third parties unless you have reviewed them and have authorization to share.

## No warranty

The software is provided “as is”, without warranty. Local-only findings are deterministic counts. Model-assisted sections are interpretations. Redaction can miss secrets expressed in ordinary prose.

## Marketplace listing

Installing `$insights` from a GitHub marketplace source does not make this plugin part of the OpenAI-curated directory tab. That tab is reserved for plugins OpenAI publishes. This package follows the same manifest, skill, and validation contract so it can be reviewed for that directory.
